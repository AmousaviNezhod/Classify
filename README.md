# Classify (UniSchedule) 🎓📅

اپلیکیشن بومی اندروید برای دریافت خودکار، تحلیل هوشمند جدول‌های PDF برنامه هفتگی، مدیریت تداخل‌ها، و مقایسه برنامه درسی با ارائه‌های دانشگاه سجاد.

---

## ✨ ویژگی‌های کلیدی

- **تحلیل هوشمند فایل‌های PDF جدول برنامه هفتگی:**
  - استخراج خودکار دروس از جداول پیچیده ساختمانی و اقماری (ساختمان ۱، ۲، ۳)
  - پشتیبانی از برنامه‌های کارگاهی، آزمایشگاهی و سایت
  - استخراج کلاس‌های خارج از جدول (آمفی‌تئاتر و اطلاعیه‌ها)
  - تشخیص خودکار روز، بازه زمانی، شماره گروه، استاد، مکان/کلاس و زوج/فرد بودن هفته
  - نرمال‌سازی متون فارسی، ارقام فارسی/انگلیسی و اصلاح خطاهای نویسه‌های عربی/CMap فونت‌ها

- **دریافت خودکار از سایت دانشگاه:**
  - رصد و دانلود مستقیم آخرین فایل‌های PDF برنامه هفتگی از پورتال دانشگاه
  - تطبیق نیم‌سال تحصیلی به‌صورت خودکار

- **مدیریت و مقایسه برنامه انتخابی:**
  - ورود برنامه دانشجو از طریق JSON یا فرم درون‌برنامه‌ای
  - مقایسه بلادرنگ برنامه انتخابی با ارائه‌های جاری دانشگاه
  - تشخیص تغییر ساعت، جابجایی اتاق/کلاس، تعویض استاد و حذف ارائه
  - سیستم انتخاب روز، فیلتر براساس هفته زوج/فرد و جستجوی پیشرفته

- **طراحی مدرن با Jetpack Compose:**
  - رابط کاربری کاملاً راست‌به‌چین (RTL) استاندارد فارسی
  - پشتیبانی از تم تاریک (Dark Mode) و تم روشن (Light Mode) متناسب با سیستم
  - کش آفلاین کامل پایگاه داده با Room بدون وابستگی به اینترنت مداوم

## 🛠 فناوری‌ها و ابزارهای مورد استفاده

| بخش | ابزار / کتابخانه |
|---|---|
| **زبان و پلتفرم** | Kotlin 2.2.x / Android SDK (Min 24, Target 36) |
| **رابط کاربری** | Jetpack Compose + Material 3 (BOM 2024.09) |
| **معماری** | MVVM + Clean Architecture + StateFlow |
| **موتور پردازش PDF** | PDFBox Android (`com.tom-roush:pdfbox-android`) |
| **وب اسکرپینگ و شبکه** | Jsoup + OkHttp 4 |
| **پایگاه داده محلی** | Android Room Database با KSP |
| **تست و صحه‌سنجی** | JUnit 4 + Robolectric (پوشش کامل سناریوهای استخراج متن و جداول) |

## 🚀 راهنمای نصب و راه‌اندازی برای توسعه‌دهندگان

### پیش‌نیازها
1. **Android Studio** (نسخه Ladybug یا جدیدتر)
2. **JDK 17 یا 21**
3. **Android SDK Platform 36**

### مراحل بیلد در محیط محلی
```bash
# دریافت مخزن
git clone https://github.com/AmousaviNezhod/Classify.git
cd Classify

# اجرای آزمون‌های واحد (Unit Tests)
./gradlew testDebugUnitTest

# بیلد نسخه دیباگ
./gradlew assembleDebug

# بیلد نسخه انتشار (Release v1.0)
./gradlew assembleRelease
```

فایل خروجی نسخه انتشار در مسیر زیر قرار می‌گیرد:
```
app/build/outputs/apk/release/app-release.apk
```
